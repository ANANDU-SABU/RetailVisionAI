# 🛍️ RetailVision AI

### AI-Powered CCTV Customer Analytics & Store Monitoring System

RetailVision AI is a Python-based Computer Vision system that analyzes CCTV footage to detect and track customers, monitor store zones, calculate occupancy, detect entry/exit events, and generate retail analytics.

The project demonstrates a practical combination of **Python, Computer Vision, YOLO, Object Tracking, SQL, FastAPI, and REST APIs**.

---

## 🎥 Demo

### CCTV Analytics Demo

The system processes CCTV footage and provides:

- 👤 Person detection
- 🎯 Unique person tracking
- 🚪 Entry/exit detection
- 📍 Store-zone monitoring
- 👥 Occupancy analysis
- ⏱️ Customer dwell-time analysis
- 📊 Event and zone analytics
- 🗄️ Database storage
- 🔌 REST API
